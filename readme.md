# Программ хангамжийн чанарын баталгаа ба туршилт - Лаб 5
B232270105 - Б.Хан-Эрдэнэ
<hr>

### Дүгнэлт

Энэ хичээлээр Postman ба Newman хэрэгслүүдийг ашиглаж систем тест хийж сурав. Үүгээр аливаа апплекешний API дуудалт хэрхэн, ямар хариу өгөх, энэ зөв байна уу эсэхийг шалгаж, тестлэж болно.

Хамгийн бодол шаардсан хэсэг бол тестийн бүрэн бүтэн дизайн гаргах хэсэг, дараа нь тестийн specification гаргах байв. Specification-аа Postman-дээр бодит тест болгон бичэх ажилд асуудал гаралгүй, хэвийн явагдсан.

Давхар алдаанд оюутан ба хичээл хоёул оршихгүй үед авч үзсэн ба server.js хэрхэн бичэгдсэн байдлаас шалтгаалан ERROR_NO_STUDENT эхэлж буцсан. Серверийг унтрааж, collection-г ажиллуулах үед бүх хүсэлтүүд унасан ба энгийн тест уналтаас ялгаатай нь oracle-н assertion огт хийгдээгүй нь юм.

server.js-д нэгэн олдсон алдаа бол /courses/:id PUT endpoint-д массив бус утга оруулахад холбоотой /registrations POST үйлдэлд сервер унаж, дараагийн тестүүд унасан. Учир нь массив биш утга дээр массивийн метөд дуудаж, TypeError алдаа гарч серверийн програм гарсан.
